Rebuild the poster (A0, 841 x 1189 mm)
1. Put the two logo files in this folder as  logo_iisc.png  and  logo_tiet.png  (PNG, transparent or white background).
2. pip install playwright matplotlib pandas pypdf  (Chromium must be available to Playwright)
3. python build_poster.py && python render.py        -> poster_A0.pdf
   Cover + poster:  replace cover.jpg with the full-resolution cover, then re-run the merge step in make_all.sh
Figures are regenerated by  python figs.py  (needs the Droplet_Intelligence_v2 results; paths at the top of figs.py).
